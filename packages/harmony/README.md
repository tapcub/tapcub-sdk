# TapCub (HarmonyOS)

TapCub analytics SDK for HarmonyOS NEXT / API 12+, Stage model, shipped as a HAR.

## Install

```bash
ohpm install @tapcub/harmony
```

Until the package is on the OHPM central repository, clone [tapcub-sdk](https://github.com/tapcub/tapcub-sdk) and use a local path in your project's `oh-package.json5`:

```json5
"dependencies": { "@tapcub/harmony": "file:../path/to/tapcub-sdk/packages/harmony" }
```

## Quick start

```ts
import { TapCub } from '@tapcub/harmony';

export default class EntryAbility extends UIAbility {
  onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
    // Only stores the config and hooks lifecycles: no collection, no device reads, no network
    TapCub.preInit(this.context, { siteKey: 's_xxx' });
  }
}

// After the user accepts the privacy policy (call right after preInit if the site does not require consent)
await TapCub.init();
```

`appId`, `appVersion` and `appBuild` default to bundleName, versionName and versionCode. Call `preInit` in `AbilityStage.onCreate` or `EntryAbility.onCreate`; otherwise the cold start and the first page are lost.

## Common calls

```ts
TapCub.track('checkout', { amount: 99, currency: 'CNY' });
TapCub.trackScreen('Checkout');
TapCub.login('u_123');                       // type: login | email | mobile | unionid | openid | custom
TapCub.setProps({ plan: 'pro' });            // user properties
TapCub.registerSuperProps({ channel: 'appgallery' });
TapCub.grantConsent(['analytics']);          // analytics | functional | marketing
TapCub.optOut();
TapCub.trackPurchase({ product_id: 'vip_month', amount: 30, currency: 'CNY' });
TapCub.flush();
const did = TapCub.getDeviceId();

Button('Buy now').onClick(() => {
  TapCub.trackClick('buy', 'Buy now');       // ArkUI has no global click hook, so report clicks manually
});
```

The SDK runs on the ArkTS main-thread event loop. Every call returns immediately; network requests are asynchronous.

## Automatic collection

| Event | Source | How to turn off |
| --- | --- | --- |
| `$app_start` / `$app_end`, sessions | `abilityLifecycle` (cold start), `applicationStateChange` (foreground / background) | Always on |
| `$screen_view` | UIObserver: covers both `router` pages and `Navigation` NavDestinations | `autoTrackScreens: false` |
| `$app_click` | Only manual `trackClick` calls | `autoTrack: false` or remote config |
| `$app_crashed` | hiAppEvent `APP_CRASH` (JS and native), reported on the next launch with the original crash time | `crashReport: false` |
| `$anr` | hiAppEvent `APP_FREEZE` (main thread blocked for 6 s) | Same as above |

Cold start time is in `$duration_ms` on `$app_start` (from process start until the first Ability comes to the foreground). Frame rate and memory sampling (`perf`) are not supported on HarmonyOS yet.

To skip a page: `TapCub.ignoreScreen('Splash')` (router page name or NavDestination name).

## Storage and privacy

- Plain keys go to Preferences (`tc_sdk`); the event queue is one file per chunk under `filesDir/tapcub_queue`, capped by default at 8 MB / 10,000 events / 7 days.
- Device ID: `harmony_odid:<ODID>` (shared by apps from the same developer; changes after a factory reset). After `reset()` a new ID is generated and the SDK no longer falls back to the ODID.
- Declares only `ohos.permission.INTERNET`. The network type is read only if the host declares `ohos.permission.GET_NETWORK_INFO`, otherwise it is recorded as `unknown`. Location, contacts and the clipboard are never read.
- Obfuscation: the HAR itself is not obfuscated. If your app enables `-enable-property-obfuscation`, add `-keep ./oh_modules/@tapcub/harmony` to the app's `obfuscation-rules.txt`, or the reported field names get renamed.

## Development

In this directory (`packages/harmony`):

```bash
pnpm test        # core sync check + tsc type check + adapters run in Node against mocked kits
pnpm sync        # copy app-sdk core changes into src/main/core
```

- `src/main/core/` is a copy of `packages/app-sdk/src/core` generated by `scripts/sync-harmony-core.mjs`. Do not edit it by hand; CI checks that both sides match.
- The adapter layer `src/main/sdk/` is also `.ts`: the core interfaces use `unknown`, index signatures and other constructs that ArkTS strict mode rejects, which `.ts` files can reference directly; app `.ets` code calls through `Index.ets`.
- `test/kits.d.ts` holds minimal hand-written declarations matching the API 12 signatures, for local type checks only; the real build runs in DevEco Studio / `hvigorw assembleHar`.
- Brand constants live in `src/main/sdk/Brand.ts`.
